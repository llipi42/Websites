# Websites

Static sites, one folder per site. Every site is self-contained — open its
`index.html` in a browser and it works, with no build step and no dependencies.

| Site | Folder | Description |
|---|---|---|
| PGD Ostrožno | [`pgd-ostrozno/`](pgd-ostrozno/) | Prostovoljno gasilsko društvo Ostrožno, Celje |

## Publishing

Any folder here can be served as-is. To publish with GitHub Pages, enable Pages
on the `main` branch from the repository root; each site is then reachable at
`/<folder>/`.
